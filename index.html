Raster data statistics

SoilGrids and WorldCover are raster WMS layers. The map displays the selected area's raster coverage, but WMS image tiles do not expose the underlying pixel values for accurate zonal statistics. Pixel-level class area statistics require raster/COG processing or a suitable WCS/API. No raster class counts or areas are fabricated here.

Methodology and limitations

OSM data are retrieved for the selected boundary extent and checked against the selected EA geometries. Line and polygon geometries are clipped or filtered before display. OSM data may be incomplete. Mapped historic pond tags are not a verified inventory of lost ponds. Protected-area tags should be checked against official conservation datasets. Statistics describe the retrieved mapped features, not necessarily all features on the ground.
